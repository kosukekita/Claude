**音声解析でイベントの「種類」（声・鳴き／モーター・機械音／接触・衣擦れ）を命名する前に、必ず `ffmpeg -lavfi showspectrumpic` のスペクトログラムを自分の目で見て判定する。** 声・鳴き＝倍音の櫛（等間隔の横縞）＋音程変化。機械音・接触音＝倍音なしのブロードバンド過渡（縦の縞）。

**Why:** 2026-08-08 Nikoboプロジェクトで、agy（Gemini）が「発声なし・動作ノイズのみ」と要約した参照動画に実はロボットの鳴き（-23dBの微小音・24.5〜25.2s）が入っており、映像タイムラインの「旋回運動」との相関だけで「モーター音」と誤ラベルして納品→ユーザー指摘で発覚。LLMのマルチモーダル要約は微小音の種類を取り違える。倍音構造は画像として一目で判別でき、自分で検証できる。

**How to apply:** ①`silencedetect`（閾値を-38〜-48dBで段階的に）でイベント時刻を列挙 ②各イベントを `ffmpeg -ss .. -t .. -lavfi "volume=15dB,showspectrumpic=s=1200x480:legend=1:scale=log"` で画像化して Read ③倍音の有無で命名 ④ユーザーの現場知識（「そこに声が入ってる」）は最優先の一次情報として扱う。関連 [[web-original-fetch-playbook]]（手段を尽くす同旨）・video-media-studio スキル「参照動画の解析」項目8が正本。
