# 複式簿記への移行トリガー（ユーザー決定 2026-08-03）

**当年の売上が 10万円以上になった時点で複式簿記へ移行する。** それまでは Google Sheets の単式台帳（青色10万円控除）で運用する。

**Why**: 青色申告の65万円控除には複式簿記＋貸借対照表＋e-Tax が必要。売上が小さいうちは手間に見合わないため、閾値を決めて後回しにする判断。承認申請自体は提出済みなので、移行すればその年から65万円控除を狙える。

**How to apply**:
- リマインドは `keiri-ledger` スキルの通知条件として実装（月次 cron が台帳の当年売上を見て、10万円到達時に1回だけ通知）。**私の記憶や人間の意識に依存させない**
- 通知が来たら、Sheets台帳を一次記録として維持したまま、会計ソフト（freee/マネーフォワード/やよい）へ取り込んで複式簿記の決算書を作る二層構成へ移行する。台帳の作り直しは不要
- 65万円控除には **e-Tax での申告**（または電子帳簿保存）も要件。紙申告だと55万円になる点を移行時に併せて伝える
