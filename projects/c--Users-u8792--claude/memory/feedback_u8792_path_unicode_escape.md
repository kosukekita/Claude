このPCのユーザー名は `u8792`。バックスラッシュ区切りの絶対パス（C:[バックスラッシュ]Users[バックスラッシュ]u8792…）をツール（Read/Write/Edit/Grep/Glob/Bash/PowerShell の path・command 引数）に渡すと、「[バックスラッシュ]+u8792」の部分が **JSON の Unicodeエスケープ（[バックスラッシュ]u + 16進4桁 8792）として解釈され、コードポイント U+8792 の漢字1文字に化け**、実在しない別の場所（Users の直後がその化け漢字になったパス）を読み書きしてしまう。この説明文自体も被害に遭ったため、生の化け漢字も生のエスケープ表記も書かず「U+8792」「[バックスラッシュ]」と表記している。

**Why:** ツール引数は JSON 文字列として渡るため、「[バックスラッシュ]+u+16進4桁」のパターンがエスケープシーケンスとして成立してしまう。ユーザー名がたまたまこのパターンに一致する。化けた書き込みは**エラーにならず静かに成功**するため、メモリファイル24件＋プラン8件が化けディレクトリ配下に蓄積していた（2026-06-11 に全件を本来の場所へ救出し、化けディレクトリは `~/.claude/backups/mojibake-rescue-2026-06-11/` に隔離済み。2026-06-14 にも同種の化けディレクトリを再削除）。

**How to apply:**
- ツールに渡すパスは**常にフォワードスラッシュ**で書く: `C:/Users/u8792/.claude/...`（全ツールで動作確認済み）
- PowerShell コマンド内では `$env:USERPROFILE` でパスを組み立てる（コマンド文字列に「[バックスラッシュ]+u8792」を直書きしない）
- 化けパスを調査・操作する必要があるときは `[char]0x8792` で構築し `-LiteralPath` を使う
- Read の内容やサイズが期待と食い違ったら、まずパス化けを疑う（`Get-Item` の `.Length` と比較）
- 記憶・設定・会話に U+8792 を書く必要があるときは**生の化け漢字を絶対に書かない**（SessionStartで再注入され API 400 を誘発する → [[feedback_settings_mojibake_path_causes_api400]]）。数値表記「U+8792」で書く。
- **被害は2系統に切り分けて考える**: (1) **自分がツール引数に書くパス** → 完全に回避可能（フォワードスラッシュ厳守。守らないのは自分のミス）。(2) **ハーネスがログ/通知に出力するパス**（例 `<task-notification>` の `<output-file>` が `C:\Users[U+8792]\...` とバックスラッシュで来る）→ こちらは制御不能だが、**読むときにフォワードスラッシュへ直してから Read に渡す**だけで実害ゼロにできる。「仕方ない」のは(2)の出力形式だけで、実害は規律で防げる。
- 再発例: 2026-06-15、Workflow の output-file をハーネス通知のバックスラッシュ表記のまま Read に渡して1回化けた（フォワードスラッシュで再試行して解決）。**通知に出たパスをコピペするときは必ずスラッシュ変換する**のが恒久対策。
- 再発例: 2026-07-14、Write の file_path をバックスラッシュで書き、グローバル記憶ファイルが化けツリー配下に生成された。化けツリーには**過去複数セッションの workflow スクリプト・scratchpad ファイルも蓄積**していた（＝再発は1回ではない）。さらに救出作業のコマンド先頭に紛れた `>` で .md がシェル実行され、**バッククォート内の `~/.config/atlascloud.key` が実行されて API キーの中身がログに露出**する二次被害まで連鎖した。教訓: ①Write/Edit の file_path も必ずフォワードスラッシュ ②**シークレットのパスをバッククォートで囲った Markdown をシェルに触れさせない**（実行・source されると key が漏れる）③復旧コマンドは1行ずつ・先頭文字を目視確認。
- 再発例: 2026-07-17、docx→PDF 作業のセッション**初手の PowerShell 引数**で直書きし化けツリーを再生成（2回）。新事実として、この日の SessionStart の記憶注入は**サイズ超過で `persisted-output` のプレビューに切り詰められ、本メモリの索引行がコンテキストに届いていなかった**。教訓: **記憶が注入される前提に頼らない**。パスは「思い出したら」でなく**無条件・反射的にフォワードスラッシュ**で書く（このPCでバックスラッシュ絶対パスを書いてよい場面は無い）。
