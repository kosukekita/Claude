便利な機能・tips（例: r.jina.ai でのWeb取得フォールバック）をどこに記載するかは、**「実際に発火する文脈」で決める**。

**Why:** ユーザーが直接使わないスキルや、専用APIで用が足りるスキルに書くと「死蔵」になる（読まれない）。CLAUDE.md は全セッション常駐するがトークンを毎回消費する。配置を誤ると、書いたのに効かない or コンテキスト汚染のどちらかになる。

**How to apply:**
- そのtipが効く文脈が**特定スキルに属さず全セッション共通**（例: WebFetch失敗時のフォールバック）なら → CLAUDE.md に最小限（1〜2行）。唯一死蔵しない置き場所。
- 効く文脈が**特定タスク・特定ツール起動時だけ**なら → そのスキル内にフォールバックとして1箇所。
- 既存の標準ツール/別スキルで足りるなら → **どこにも書かない**（必要時にその場で指示すれば済む）。
- 外部プロキシ/外部サービス系（jina等）は**セキュリティ注意とセット**で書く。認証付き・機密・個人情報URLには使わせない（ユーザーは医学研究データ・要ログインリソースを扱う）。

**標準ツールと重複するスキル機能は削る:**
- スキルが標準ツール（WebFetch/WebSearch）や別の導入済みツール（chrome-devtools-mcp）と機能重複している部分は削除してスリム化する。例: browser-automation の CDPモードは chrome-devtools-mcp と完全重複 → 削除し、Playwright固有機能（クリーン起動・ログイン状態保存・ネットワークモック・トレース・動画録画）だけ残した。
- **削除前に必ず grep で参照を確認**してから消す（他スキル/プラグインが参照していないこと）。
