画像生成（人物・キャラクターシート含む）でユーザーがスタイルを指定していない場合、**既定は常にリアル（フォトリアル・実写風）**。イラスト調／アニメ調は明示的に指定されたときだけ使う。

**Why:** 2026-07-07 のキャラクターシート生成で、「リファレンス・キャラクターシート」という語からイラスト調（モデルシートの慣習）と推測して生成したところ、ユーザーの意図はリアル画像で手戻りになった。「どういった画像が欲しいかを先に聞いてほしかった。何も言わなければリアル画像が欲しい」との明示フィードバック。

**How to apply:**
1. スタイル未指定の画像依頼 → フォトリアルで生成する（推測でイラスト調に倒さない）。
2. スタイルの解釈が割れそうな依頼（シート・図解風など）は、生成前にひとことスタイルを確認する。
3. リアルのキャラクターシートは「モデルコンポジット／キャスティングシート」形式（全身正面・側面・背面＋バストアップ＋表情差分の実写グリッド）で組む。
4. フォトリアル時は video-media-studio の `reference/realism-naturalization-prompts.md`（スターター3個＋症状別）を仕上げ層に足す。
5. 正本ルールは video-media-studio SKILL.md「人物画像のプロンプト構成テンプレート」節の「★スタイル既定＝リアル」に記載済み（本記憶はポインタ兼経緯）。関連 [[project_grok_media_skill]]
