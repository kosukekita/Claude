Lower Limb FEA PINN の再解析では、異常の原因が特定できた場合、**その原因だけを解消して再解析する**。セグメンテーション不良が原因ならラベルだけを修正し、メッシュサイズ、ステップ数、材料則、境界条件などは元解析と同一に保つ。

原因修正と同時に別の解析条件を変更すると、結果が正常化した理由を分離できず、元コホートとの比較可能性も失われる。複数条件の変更が必要な場合は、ユーザーの明示承認を得て、主解析とは別の感度解析として扱う。

2026-07-30 の UZU00003_R は、TotalSegmentatorラベルだけを変更し、元の214側と同じ4 mm・400ステップで再解析する。UZU00051_L、UZU00075_L、UZU00118_LはTotalSegmentator化と2 mm化を同時に行ったため、正常化の原因を分離できないが、ユーザー指示により再解析もスライドへの追記もしない。

**Why:** 原因がセグメンテーションと判明した後にメッシュも4 mmから2 mmへ変更すると、因果 attribution と214側との直接比較が不可能になるため。

**How to apply:** 再解析前に「特定原因」「変更する一項目」「固定する全条件」を明示し、実行コマンドと出力監査に残す。原因以外の条件はユーザー承認なしに変更しない。
