# character-sheet-template.md — キャラクターシート（リファレンスシート）作成テンプレート（video-media-studio）

`SKILL.md` の「キャラクターシート（リファレンスシート）作成」節が defer する正本。
参照画像（実写人物 or イラスト/アニメ/漫画/3D/デフォルメキャラ）1 枚から、**同一人物・同一キャラクターに見える
設定資料（三面図＋顔アップ＋表情集＋顔パーツ＋髪詳細＋別角度）を 16:9 一枚絵で生成する**ための固定テンプレート。
目的はプロフィール紹介ではなく、**キャラクター制作・AI 画像生成・モデル固定用の視覚資料**（以後の同一人物量産・i2v・v2v のマスターリファレンスになる）。

## ワークフロー

1. **参照画像の正立確認**: スマホ縦長写真は EXIF で 90° 横倒しのことがある。`ffmpeg -noautorotate -i src.jpg -vf transpose=2 -map_metadata -1 up.jpg` で正立を確認してから使う（SKILL.md の既存ルール）。
2. **バックエンド選択**（参照画像を受け付ける経路のみ。`gen_image.py` ローカル系は参照非対応・Grok `image_edit` はヘッドレス不発火で不可）:
   - **第一選択 = Codex(GPT Image)**: 参照忠実度・複数パネルレイアウト・画中日本語テキストの総合力で最良。`codex exec --skip-git-repo-check --sandbox workspace-write -i ref.png < prompt.txt`（`-i` 添付＋プロンプトは stdin。位置引数併用は不可）。出力は `~/.codex/generated_images/<sid>/ig_*.png` から回収。
   - **フォールバック = Qwen-Image-Edit（ローカル・NSFW 可）**: Codex が参照画像（露出のある服等）を拒否したとき。`gen_qwen_edit.py --image ref.png`。※複数パネル一枚絵＋日本語ラベルの品質は未実測 — 初回はまず 1 枚出して確認してから本番にする。
3. **テンプレートをそのまま使って生成**: 下のプロンプトテンプレートを prompt.txt に書き出し、参照画像を添付して投げる。**テンプレートは自己完結**（構図・背景・光・枚数を自身で規定する）なので、人物 6 要素テンプレートの確認フローは適用しない。**テンプレートを改変・削減する場合（パネルを減らす、比率を変える等）だけ事前にユーザー確認**。
4. **検証**: ①各パネルが元画像と同一人物/同一キャラに見えるか（顔・髪・体型を目視比較）②絵柄が維持されているか（実写→実写 / アニメ→アニメ）③日本語ラベルの文字化け・英語混入 ④パネル欠け・顔の重複。崩れたパネルがあれば再生成（seed を変える or 崩れた項目を強調して再指示）。
5. **納品と使い回し**: 完成シートは以後の**マスターリファレンス**。Codex `-i` / `gen_qwen_edit.py --image` / v2v `--face-ref` / i2v `--image` の参照元として使う。

## プロンプトテンプレート（原文・そのまま使う）

```
添付画像の人物・キャラクターを最重要リファレンスとして使用し、同一人物・同一キャラクターに見えるキャラクターシートを作成してください。

添付画像が実写なら実写調、イラスト・アニメ・漫画・3D・デフォルメなら、その絵柄・線・塗り・質感・デフォルメ度を維持してください。
勝手に実写化・イラスト化・別絵柄化しないでください。

目的はプロフィール紹介ではなく、キャラクター制作・AI画像生成・モデル固定用の視覚資料です。
名前、年齢、性格、趣味、説明文などのプロフィール要素は不要です。
画像内の文字は、各パネルを示す短い日本語ラベルのみ入れてください。英語表記は使わないでください。

画像形式：
16:9の横長一枚絵。白〜薄いグレー背景。高解像度。薄い罫線やボックスで整理された、見やすいキャラクターシート風レイアウト。

最重要条件：
元画像の顔、目、眉、鼻、口、輪郭、髪型、髪色、肌や塗りの質感、体型、雰囲気、服装の印象を忠実に再現してください。
別人・別キャラクターにしないでください。
過度な美化、簡略化、体型変更、顔の作り替えは禁止です。
元画像に写っている一時的な小物・食べ物・背景・ポーズ・手持ちアイテムは、キャラクター設定に必要ない限り除外してください。

服装：
元画像の服装が明確なら維持してください。
全身が分からない場合は、元画像の雰囲気に合う自然な服装で補完してください。
正面・横・後ろでは、同じ服装・同じ髪型・同じ体型で統一してください。
過度な露出、下着、水着、性的な衣装は避けてください。

入れる内容：
【全身】正面・横・後ろ
【顔アップ】正面・横顔・斜め45度
【表情】通常・笑顔・にっこり・真剣・驚き・照れ・考え中・困り顔
【顔パーツ】目・眉・鼻・口・耳・輪郭・肌・質感
【髪の詳細】前髪・横髪・後ろ髪・髪の流れ
【別角度】斜め左・斜め右・上から・下から・後頭部

レイアウト：
資料として見やすく、余白をきれいに取り、各項目をボックスで整理してください。
雑誌プロフィール風、履歴書風、ポスター風にはしないでください。
長文説明は入れず、日本語の短いラベルだけにしてください。

ネガティブ指定：
別人、別キャラクター、顔が変わる、絵柄が変わる、勝手に実写化、勝手にアニメ化、髪型変更、髪色変更、服装バラバラ、体型変更、過度な美化、過度な簡略化、プロフィール文、名前、年齢、性格、趣味、英語ラベル、長文説明、文字化け、読みにくい文字、雑なレイアウト、低解像度、顔の歪み、変な目、手の破綻、指の破綻、重複した顔、性的な衣装、下着、水着、不要な小物、食べ物をくわえる、ランダムな物体、ごちゃごちゃした背景
```

## 補足ルール

- **★ローカルモデル（Qwen-Image-Edit 等）で NSFW シートを作るときの構成調整（2026-07-07 ユーザー確定）**: ローカルモデルは Codex(GPT Image) と違い、**小さいパネルを1つ1つ精密に描く解像度・能力が無い**（小さい顔タイルの羅列は崩れる／同一性が落ちる）。そこでローカル経路の NSFW シートは次のように「入れる内容」を調整して生成する（ユーザー確定済みなので事前確認は不要）:
  - **【表情】の行（通常・笑顔・…困り顔の8連）は丸ごと削除**する。← 小さい顔タイルが最も崩れる。
  - **【顔アップ】（正面・横顔・斜め45度）と【顔パーツ】（目・眉・鼻・口・耳・輪郭・肌・質感）は残す**。← 表情とは別物、同一性の核なので必ず入れる。
  - **【全身】は正面・背中を何枚も並べず、各1枚程度に絞る**（正面1・横1・後ろ1 で十分。同じ向きの全身を量産しない）。
  - 【髪の詳細】【別角度】も残す。
  - Codex 経路（SFW シート等）はフル構成（表情含む）でよい＝この調整は「ローカル×NSFW」の組み合わせに限る。
- **入れ墨の固定ルールとの整合**: 元画像に入れ墨が**無い**場合はネガティブ指定の末尾に「入れ墨・タトゥーの追加、肌への文字や模様の追加」を足す（SKILL.md の固定ルール）。元画像に入れ墨が**ある**場合は同一性優先でそのまま再現する（勝手に消さない）。
- **絵柄判定を先にやる**: 生成前に参照画像を Read で見て「実写 / アニメ / 漫画 / 3D / デフォルメ」を自分で判定し、テンプレートの絵柄維持指示がどちらに効くかを把握しておく（検証時に「勝手に実写化/アニメ化されていないか」を見る基準になる）。
- **16:9 の近似**: GPT Image の出力サイズは固定刻み（横長は 1536×1024 ≈ 3:2）。テンプレートの「16:9 横長」はレイアウト指示として機能するが、厳密な 16:9 が必要なら生成後に `edit_video.py` 系ではなく ffmpeg の pad/crop（`reference/ffmpeg-recipes.md` の resize-crop-pad）で調整する。
- **自然化プロンプトとの関係**: 実写調シートで「AIっぽさを消したい」要望が付いたら `reference/realism-naturalization-prompts.md` から提案してよい。ただしシートは資料であり SNS 写真ではないので、レイアウト指示と矛盾する項目（生活感のある背景等）は入れない。
- **パネル一部だけ欲しい場合**（表情集だけ・三面図だけ等）: 「入れる内容」を該当ブロックだけに削って使う（削減はユーザー確認済みの場合のみ。ラベル・レイアウト・最重要条件・ネガティブはそのまま残す）。
