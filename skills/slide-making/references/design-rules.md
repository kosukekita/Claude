# Design Rules — slide-making

デザインシステムの完全リファレンス。`template.html` の CSS 変数と対応。

---

## 1. カラーパレット

| 役割 | 変数 | HEX | 用途 | 配分目安 |
|------|------|-----|------|---------|
| ベースカラー | `--base-color` | `#F9F9F9` | スライド背景全体 | 約70% |
| テキストカラー | `--text-color` | `#1A1A1A` | 見出し・本文・表の罫線 | 約25% |
| メインカラー | `--main-color` | `#0071BC` | 重要な強調（極力控える） | 約4% |
| アクセントカラー | `--accent-color` | `#FF5050` | 警告・ネガティブ（最後の手段） | 約1% |

**原則**: メインカラーとアクセントカラーの合計使用率は **5% 以下** を目標にする。

---

## 2. フォントサイズ

| 要素 | 変数 | サイズ | 使用箇所 |
|------|------|--------|----------|
| タイトル | `--font-size-title` | 50pt | スライドの大見出し（1スライドに1箇所のみ） |
| 見出し | `--font-size-heading` | 35pt | セクション見出し、図表タイトル |
| 本文 | `--font-size-body` | 25pt | 箇条書き、表のデータ、説明テキスト |
| スライド番号 | （直書き） | 18pt | 右下 |

**フォントファミリー**: `'Noto Sans JP', 'Inter', 'Meiryo', 'Yu Gothic UI', sans-serif`

---

## 3. 余白

| 設定 | 値 | 換算 |
|------|-----|------|
| 上下左右の最小余白 | 48px | 0.5インチ（96dpi基準） |
| CSS 変数 | `--margin-edge` | `padding: var(--margin-edge)` で適用済み |

---

## 4. 強調の優先順位

強調を加える際は、以下の順に試みる。**メインカラー・アクセントカラーはなるべく使わない**。

### 優先度 1 — 下線（`.emp-u`）

```html
<span class="emp-u">強調したい語句</span>
```

**OK**: 術語の初出、定義、キーワード1〜2語  
**NG**: 1行丸ごと / 3語以上の文節 / 既に太字の箇所

### 優先度 2 — 文字と背景の反転（`.emp-inv`）

```html
<span class="emp-inv">強調したい語句</span>
```

**OK**: 数値・指標のハイライト、最重要1語  
**NG**: 複数箇所に多用 / 段落全体

### 優先度 3 — メインカラー（`.emp-main`）

```html
<span class="emp-main">強調したい語句</span>
```

**OK**: グラフの主系列ラベル、1スライドあたり1〜2語のみ  
**NG**: 下線・反転で対応できる箇所 / 3語以上

### 優先度 4 — アクセントカラー（`.emp-accent`）

```html
<span class="emp-accent">強調したい語句</span>
```

**OK**: 警告数値、ネガティブ指標の1語  
**NG**: ポジティブな強調 / 1スライドで2箇所以上

---

## 5. 表のルール

```css
/* 横線のみ — 縦線は一切使用しない */
table { border-collapse: collapse; }
th, td { border: none; border-bottom: 1px solid var(--text-color); }
thead th { border-bottom-width: 2px; }
table tr:last-child td { border-bottom: 2px solid var(--text-color); }
```

**NG 例**: `border: 1px solid` で全罫線を引く（縦線が現れる）

---

## 6. 略語ルール

| 状況 | 書き方 |
|------|--------|
| 初出 | フルテキスト（略語）例: 「人工知能（AI）」 |
| 2回目以降 | 略語のみ 例: 「AI」 |
| 英語略語（日本語スライド） | 初出に日本語訳を付記 例: 「EHR（電子健康記録）」 |

---

## 7. ビジュアル優先の判断基準

| 情報の種類 | 推奨ビジュアル |
|------------|---------------|
| 時系列データ | 折れ線グラフ（Chart.js） |
| 比率・構成 | 円グラフ / 積み上げ棒グラフ |
| 比較（2〜4項目） | 棒グラフ / 横並び比較 |
| ワークフロー | 矢印付き横並びアイコン |
| 対立・二項 | 左右 2 列レイアウト |

テキストだけで表現しようとする前に「図にできないか？」を先に考える。
