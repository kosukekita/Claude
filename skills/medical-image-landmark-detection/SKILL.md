# Medical Image Landmark Detection

CT/MRIのセグメンテーションラベルから、解剖学的ランドマーク（点・中心・軸）を**全症例で堅牢に**自動同定する手法論。1症例で動いても、100症例では別の壊れ方をする — その汎化を最初から設計する。

## 核心原則（順守すれば今回の失敗を全部防げる）

**1. 向きは推定する前に「画像メタデータで確定」する。**
近位/遠位・左/右・頭尾側は、PCA長軸の符号推定に頼る前に **DICOM direction matrix（ITK `GetDirection()`）** で確定できる。「向き不変にする」を建前にこの自明な確認を飛ばすと、遠位（膝）を近位（骨頭）と誤検出する。`direction[:,2]` のworld-S成分の符号で「index z 増加=頭側か」が決まる。**まず向きを固定し、対象端だけを候補にする。** 両端を平等に扱うと非対象側が紛れ込む。

**2. 臨床事前（正常半径など）はQCに使い、検出のチューニングには使わない。**
「日本人骨頭半径22-25mm」のような事前知識は、**ハード/ソフトの二段階QCフラグ**に使う。これを検出器のパラメータ（半径上限26mm等）に焼き込むと、その症例群にoverfitし、大柄・小柄・病的形状で真値を切り捨てる。検出はできるだけ素直に、判定で締める。

**3. 1手法に固執しない。原理の異なる2手法を走らせ合議する。**
RANSAC（ロバスト最小サンプル）とHough（法線投票）は**勝ったり負けたりする** — RANSACは近遠位取り違えで隣の骨へ、Houghは法線誤ピークで骨外へ飛ぶ。両方走らせ「一致すれば信頼、不一致なら片方が破綻」と扱う。合意例は自動採用、不一致だけ精査。

**4. 不一致の採用判定は「左右対称性」が最も頑健。**
同一個体の左右ランドマークはほぼ同径・同高。一方が両手法一致（信頼）なら、それを物差しに反対側の正しい方を選べる。RMSや複数指標の重み付けスコアより、対称性は重み調整なしで効く。

**5. 数値で「成功」と言わない。必ず可視化で中心が乗るか目視する。**
半径やRMSが妥当でも、中心が頸部寄りにずれていることがある（軸状断だけ見ると見逃す）。**冠状断・矢状断も含めCT実画像に重ねて目視**。全症例を一覧化（モンタージュ画像 or 画像埋込）し、QCフラグ症例を先頭に。

**6. 全自動で正解と言い張らず、人間チェックポイントを必ず1つ残す。**
QCフラグ（2手法不一致・半径域外・左右差大・RMS大）を立て、**フラグ症例だけ人間の目に回す**。100+例でフラグが数%なら現実的な目視量。

## 標準パイプライン

```
1. ラベル表面点抽出（mask erosion差分。巨大全身CTはラベルbbox内に閉じて高速化）
2. DICOM頭尾側(S-I)軸で近遠位を確定 → 対象端(近位など)32%だけを候補に
3. 検出器を2つ走らせる:
   - RANSAC球/平面フィット（緩い半径ゲート、シード固定で決定論化）
   - Hough法線投票（内向きnormal=EDT勾配、c=p+r·n に投票）
4. 採用: 2手法が近ければRMS小、離れていれば左右対称性で骨頭らしい方
5. QCフラグ: 中心間距離大/半径域外/左右差大/RMS大
6. 全例可視化（中心点・冠状断拡大）+ フラグ症例を先頭にした一覧
```

## ロバスト球フィットの要点

- **代数球フィット(`sfit`)**: `A=[2P,1], b=ΣP²` の線形最小二乗で中心と半径を同時に得る。`Σ(‖P-c‖-r)²`（球面残差）を最小化。`Σ‖P-c‖²`（重心）とは別物 — 重心は非球面に引かれて外れる。
- **trimmed/robust**: 残差 > `max(1.5, 2.5·MAD)` の点を反復除去。MAD=median(|e−median(e)|)、SDと違い外れ値に頑健。
- **RANSAC**: ランダム4点で球→`|dist-r|<tol`のインライア最大を採用→インライアで再フィット。**シード固定で再現性確保**（研究用途では必須）。4点球フィットは有効サンプル率が低い(半径ゲートを厳しくするほど)ので、緩いゲート+反復で当てる。
- **Hough法線投票**: 各表面点の内向きnormalは**ラベルmaskのEDT勾配**から得るのが階段ノイズに頑健。`c=p+r·n` に半径レンジで投票、最頻格子の重心を中心、近傍点で球フィットしてrefine。頸部巻き込みに原理的に強い（非球面のnormalは中心に集中しない）。

## よくある失敗（実際に踏んだ）

| 失敗 | 原因 | 対策 |
|------|------|------|
| 隣の骨（膝）を中心に検出 | 近遠位を推定で誤り両端平等に扱った | S-I軸で確定し対象端だけ候補に（原則1） |
| 半径が小さく出て局所丸みを拾う | 候補領域に頸部混入＋スコアが弱い | 領域を対象端に絞る＋半径事前はソフトに |
| 特定症例群でだけ動く | 臨床事前を検出器に焼き込みoverfit | 事前はQCに、検出は素直に（原則2） |
| 軸状断で乗って見えたが実は頸部寄り | 1断面だけで目視判断 | 冠状断・矢状断も重ねる（原則5） |
| 実行ごとに結果が変わる | RANSACシード未固定 | シード固定で決定論化 |
| 巨大全身CTで激遅(1本20秒+) | 全配列に処理 | ラベルbbox内に全処理を閉じる(→4.6秒) |

## 性能・運用の注意

- 全身CT配列は (z~2000, 512, 512) と巨大。erosion/EDT/gradient は**ラベルbbox内**で計算する。
- 多数例スイープ・CT重ね可視化は**重い** → バックグラウンド実行にし、ツールのtimeout引数に当てない。
- 可視化は**中心点（白縁の塗り円）のみ**が見やすい（十字・輪郭円はランドマークを隠す）。冠状断は中心±55mmに拡大。
- 一覧は**画像埋込のモンタージュ**が確実（相対参照HTMLは画像が表示されないことがある）。フラグ症例を先頭に橙枠で。

## いつ使わないか

- 表形式データの予測モデル → ai-prediction-model
- セグメンテーション自体の学習（本スキルは**既存ラベルからの幾何抽出**が前提）
- ランドマークが1個・1症例だけの単発作業（汎化設計のオーバーヘッドが不要）
