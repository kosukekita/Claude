# Icon Import Map

Use this file when you need the exact import statement and JSX for an icon in a React / React Native UI. Every row is a direct copy-paste of the icon's import code and usage — do not paraphrase or re-type from memory; copy the exact `Icon Name`, `Library`, `Import Code`, and `JSX Usage` cells into your implementation. The default library is Phosphor (`@phosphor-icons/react`); the Style Config and Guideline rows at the end give per-style overrides and the Phosphor→Heroicons fallback strategy.
