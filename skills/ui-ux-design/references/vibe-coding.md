# Vibe Coding UI — AI UI生成のベストプラクティス

AIでUIを生成する際に品質を上げる7つの原則。

## 1. スケッチ優先、プロンプト後
テキストから始めない。**Excalidraw** 等でワイヤーフレームを描き、ボックス・ボタン・画像配置を視覚化してからAIに渡す。「この構造に正確に従って」と指示する → AIは想像より模倣が得意。

## 2. 好みのUIをスクショ
**Dribbble**, **Mobbin**、気に入ったサイトから具体的なセクションをスクショする。ナビバー・プライシングカード・ヒーローセクション等を個別にキャプチャし、「このスタイルをコピーして」と添付すると結果が劇的に改善する。

## 3. ムードボードでカラー指定
「モダンで温かみのある」では毎回同じ青になる。**Nano Banner** 等のムードボード生成ツールで画像を作成し、「このカラーパレットを参考に」と渡す。

## 4. コード前にデザインシステム定義
ブランドカラー・タイポグラフィ・スペーシングルールを先に決める。一貫性のなさがAI UIの最大の問題。SKILL.md の Step 2 でデザインシステムを生成してから実装する。

## 5. アンチパターンルールを厳守
AIデフォルトのグラデーション禁止・Inter+Lucide 脱却・generic コンテンツ回避を適用する。「他のAIアプリと同じ見た目にするな」をシステムに組み込む。

## 6. スクショを主要コミュニケーション手段に
AIは模倣が得意、想像が苦手。視覚的コンテキストを多く与えるほど推測が減る。「クリーンに」と書くより、クリーンの実例を見せる。

## 7. フォントとアイコンで差別化
AIデフォルトの Inter + Lucide は即座にAI生成バレ。**Google Fonts** からユニークなフォントを選択し、Lucide を **Phosphor** / **Heroicons** / **Tabler** に変更する。小さな変更でテンプレート感が消える。
